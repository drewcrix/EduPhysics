# Precomputed CFD dataset

Generated by `python -m eduphysics_fluids generate` (see `../IMPLEMENTATION.md`, sections 9–10).
Do not edit by hand; regenerate or rebuild the manifest with `python -m eduphysics_fluids manifest`.

* `manifest.json` — index of all cases (headline coefficients, flow classes), airfoil geometry and
  thin-airfoil values, validation results.
* `cases/<id>.json` — one simulation: coefficients, surface C_p and C_f, force history, stagnation and
  separation points, solver metadata.
* `cases/<id>.fields.bin.gz` — velocity and pressure on a uniform display grid (12-bit, row-delta coded,
  gzip).
* `validation.json` — grid study and cylinder benchmark results.

Case ids: `naca<airfoil>_re<Re>_a<alpha>[_<variant>]`, e.g. `naca2412_re500_a-4`.
